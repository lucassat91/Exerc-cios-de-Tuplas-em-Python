# Exercícios de tuplas em Python

Sete scripts de prática com **tuplas**, cada um resolve um problema e mostra o resultado no terminal.

| Script | Exercício | Conceitos |
|---|---|---|
| `1.py` | Tupla com os dias da semana: primeiro e último dia | indexação positiva e negativa |
| `2.py` | Soma de uma tupla de 5 números com laço | `for`, acumulador |
| `3.py` | Desempacotamento de tupla (nome, idade, profissão) | *unpacking* |
| `4.py` | Contagem de ocorrências e posição de um valor | `count`, `index` |
| `5.py` | Análise de vendas: maior, menor, média e quantas ficaram acima da média | `max`, `min`, `sum`, `len`, formatação |
| `6.py` | Números repetidos e quantas vezes aparecem | `count`, lista de já processados |
| `7.py` | Ranking de produtos por preço, do maior para o menor | tupla de tuplas, ordenação manual (*bubble sort*), `enumerate` |

## Como executar

```bash
python3 1.py
```

Troque `1.py` pelo script que quiser. Não há dependências externas. Basta ter o Python 3 instalado.

## O que pratiquei

- Tuplas como estruturas imutáveis e como registros (`("Notebook", 4500)`)
- Converter tupla em lista quando é preciso reordenar
- Implementar a ordenação à mão para treinar a lógica, em vez de usar `sorted`
